# 移动回复丢失验收方法源码

本目录是本轮实际方法的逐字节归档。`FROZEN-SOURCE-INDEX.json`记录原执行路径及摘要。原冻结计划绑定实际源码位置；把归档复制到别处，不能直接消费旧计划。另一个环境必须重新核对依赖、审阅并冻结新的计划。

receiver-method先验证真实调用方管道隔离；f2-method只执行固定R4的单次正常确认及原ID查询。F1调查脚本仅适用于用户明确授权的那一个原操作，不是批量恢复入口。不得运行它们触及旧F4或旧source recovery01。

运行记录、工程、状态库、token、secret和原始转储均不在此目录。当前结果与限制见FIRST_VERSION_HANDOFF.md指向的账本。方法代码不改变产品、SDK或EXE；不提供写盘前中断、真实进程被杀或掉电恢复的通过证据。

原F2控制器223在服务自然完成和接收方EOF之后，误要求可选replayed字段，原失败保持。`f2_readonly.py`是未消费的09bf草稿；当前分离方法为`f2_readonly_02.py`，只完成原ID查询、已知消费token的拒绝与独立SDK读回，不重跑原写入。两份独立审查报告记录方法迁移与原失败。
