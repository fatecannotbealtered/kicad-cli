Use the final bound EXE and public `sch objects`/`sch edit` guide in `SCH_GEOMETRY.md`.
Copy a fixture into owned work, query new selectors, freeze exact input/scope/configuration,
inspect the published candidate and confirm only the declared change once. Use official
KiCad10.0.6 XML/ERC/SVG and independent geometry/raw-pin reading; do not import the product
parser as independent truth. Requery after save before a continuation edit.

prospective method bindings/results are linked from `docs/evidence/windows-sch-geometry-20261021`.
