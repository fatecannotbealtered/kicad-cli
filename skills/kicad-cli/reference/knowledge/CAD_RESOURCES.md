# CAD resources and knowledge

Symbol and footprint libraries supply CAD objects. Team design standards supply
engineering requirements. Tool reference supplies the current command contract.
Having a library is not evidence that the design complies with a team standard.

Use the configured KiCad installation and project-local library tables. Query the
current project and supported library/schematic commands before editing. Preserve
source identity, units, pin/pad mapping and project dependencies. Do not replace a
missing library with an unrelated same-named library or scan unrelated directories.

External KiCad installations, libraries and team standards retain their own licenses.
They are not covered by the product's Apache-2.0 license. The bundled SDK is separately
licensed; a knowledge entry cannot grant redistribution rights.
