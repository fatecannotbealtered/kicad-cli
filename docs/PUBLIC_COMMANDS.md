## Syntax and global options

- command path, then named flags; no positional input values
- bare flag or =true/=false; no 1/0 or separate values
- Command scalars reject repeated flags. The generic multiple-value parser expands CSV/repeated inputs and retains first occurrences; JSON array text is not a generic list input. Command constraints apply before that generic deduplication: power-task nets/classes and plot/Gerber layers reject repeated names. Distinct layer aliases that resolve to the same layer also refuse. Global booleans/format use the last effective value. Read each command's selection constraints.
- root --version only; authenticated runtime required
- SDK-free root bootstrap accepts no arguments, exactly one --help/-h/help, or --check-environment with optional --compact. Normal command flags still use the authenticated pinned runtime; explicit invalid overrides never fall back.
- fields projects top-level data, never reduces computation
- scope plus dry-run, inspect preview, identical parameters plus confirm; token is not authorization
- Refusal means protected engineering inputs/outputs unchanged; previews and queries may create owned state/evidence/configuration. Inspect explicit test boundaries.
